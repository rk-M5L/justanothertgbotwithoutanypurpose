# justanothertgbotwithoutanypurpose
Telegram bot for Amnezia VPN key distribution, site uptime checks, and domain list management (as txt file).

## Usage

### 1. Clone the repository:
```bash
git clone https://github.com/rk-M5L/justanothertgbotwithoutanypurpose
cd justanothertgbotwithoutanypurpose
```

### 2. In ```core.py``` change:
```python
TOKEN = "TOKEN HERE"
ADMIN_id = "YOUR ID HERE"
```
### 3. Run it (lol)
```bash
python3 ./core.py
```
